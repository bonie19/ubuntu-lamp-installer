# Ubuntu LAMP Installer
One-click installer for Apache, PHP, MySQL Community Server and Composer on Ubuntu 22.04/24.04.


Automatic installer for:

- Apache 2.4
- PHP
- MySQL Community Server
- Composer

## Installation

sudo apt update
wget https://raw.githubusercontent.com/bonie19/ubuntu-lamp-installer/main/install_lamp.sh

chmod +x install_lamp.sh

sudo ./install_lamp.sh
